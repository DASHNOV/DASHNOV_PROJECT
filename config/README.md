# Configuration

## Fichiers de configuration

### .env.example
Template des variables d'environnement pour le serveur.

Copier vers \src/server/.env\ et modifier selon votre environnement.

### SQL.env.example
Template de configuration SQL Server.

Copier vers \src/server/config/SQL.env\ et configurer vos parametres SQL.

## Environnements

- **Development**: Variables dans .env
- **Production**: Variables configurees lors de l'installation offline
